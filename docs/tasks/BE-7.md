# [Backend] Lên kế hoạch phát triển tổng quan Backend

## Mô tả

Tạo file `.md` mô tả lộ trình phát triển từng giai đoạn cho Backend của hệ thống, ko đi sâu vào chi tiết triển khai, kế hoạch chỉ dừng lại ở mức thiết kế cấu trúc, luồng hoạt động của các chức năng.

## Kết quả

- File `.md` chứa nội dung mô tả các giai đoạn phát triển cho Backend. 
- Mỗi giai đoạn cần đặt mục tiêu rõ ràng, hoàn thiện một chức năng hoặc nhóm chức năng cụ thể theo đặc tả yêu cầu `docs/requiments_specification/Requirements_Specification.md` và đặc tả API `docs/api/api_contract.md`.
